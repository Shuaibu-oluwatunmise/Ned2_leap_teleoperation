LEAP MOTION + NIRYO NED2 ROBOT CONTROL SETUP INSTRUCTIONS
================================================================

OVERVIEW
--------
Control a Niryo Ned2 robotic arm using Leap Motion hand tracking.

PREREQUISITES
-------------
- Windows laptop with Leap Motion Controller (LM-010)
- Ubuntu machine/VM with ROS2 Jazzy 
- Niryo Ned2 robot at IP 192.168.8.143
- Both Windows and Ubuntu on same network

PART 1: UBUNTU SETUP (ROS2 + Robot Driver)
==========================================

1. Run the automated setup script:
   python3 setup_niryo.py

2. Place these files in ~/ros2_drivers_ws/:
   - hand_receiverV2.py
   - robot_controllerV2.py
   - launch_driver.sh
   - setup_ros2_env.sh

3. Make scripts executable:
   cd ~/ros2_drivers_ws
   chmod +x launch_driver.sh
   chmod +x setup_ros2_env.sh

PART 3: RUNNING THE COMPLETE SYSTEM
===================================

IMPORTANT: Before starting, ensure no duplicate drivers are running:
   ps aux | grep ros2_driver
   (Should show nothing or only ONE instance)

STEP 1 - Start Ubuntu Robot Driver:
Terminal 1:
cd ~/ros2_drivers_ws
./launch_driver.sh

Wait until you see: "[INFO] Bridge node initialized for robot with ip: 192.168.8.143"

STEP 2 - Start Hand Data Receiver:
Terminal 2:
cd ~/ros2_drivers_ws
unset ROS_DISCOVERY_SERVER
source /opt/ros/jazzy/setup.bash
source install/setup.bash
export ROS_DOMAIN_ID=1
python3 hand_receiverV2.py

STEP 3 - Start Robot Controller:
Terminal 3:
cd ~/ros2_drivers_ws
unset ROS_DISCOVERY_SERVER
source /opt/ros/jazzy/setup.bash
source install/setup.bash
export ROS_DOMAIN_ID=1
python3 robot_controllerV2.py

Wait for: "Home position reached - ready for gesture activation"

STEP 4 - Start Windows Hand Streaming:
Windows PowerShell:
cd C:\Users\[username]\leap_motion_control
leap_env\Scripts\activate
python hand_stream.py

OPERATION
---------
- Move your RIGHT HAND above the Leap Motion sensor
- Hold POINTING gesture for 2 seconds to START mirroring
- The robot arm will mirror your hand movements
- Hold PEACE gesture for 2 seconds to STOP mirroring
- Keep movements slow and controlled
- Press Ctrl+C in any terminal to stop

TROUBLESHOOTING
---------------
Duplicate Driver Error:
- If you see warnings about "multiple action servers":
  pkill -9 -f ros2_driver
  ros2 daemon stop
  sleep 2
  Then restart from STEP 1

Network Issues:
- Verify both machines on same network: ping [ubuntu-ip]
- Check Ubuntu firewall: sudo ufw allow 9999/udp
- Update IP address in hand_stream.py

Robot Issues:
- Ensure robot is powered and connected to network
- Check robot calibration status
- Verify robot namespace in configuration (should be "Three")
- Verify only ONE driver running: ros2 node list (should show only one /ros2_driver_Three)

Hand Tracking Issues:
- Ensure good lighting above Leap Motion sensor
- Keep hands 20-60cm above device
- Check Ultraleap Visualizer shows hands

SAFETY NOTES
------------
- Robot has built-in workspace limits
- Start with small, slow movements
- Emergency stop: Press Ctrl+C in robot_controller terminal
- Always supervise robot operation

SUCCESS INDICATORS
------------------
1. Terminal 1 (driver): "Bridge node initialized for robot with ip: 192.168.8.143"
2. Terminal 2 (receiver): "Stats: X packets, Y pkt/s, last: Z.Zs ago"
3. Terminal 3 (controller): "Home position reached - ready for gesture activation"
4. Windows: "Frames: X | FPS: Y | Hands: Z"
5. After pointing gesture: "MIRRORING STARTED - Natural hand control active"
6. Robot arm moves smoothly following hand with NO warnings
